# Hospital Appointment No-Show Analysis

## Project Overview

This project analyzes hospital appointment data to identify factors influencing patient attendance and no-show behavior.

The analysis was performed using Python, MySQL, and Power BI to uncover patterns related to patient demographics, waiting time, medical conditions, and appointment scheduling.

## Dataset Information

- Total Records: 110,527
- Unique Patients: 62,299
- Features: 25 Columns
- Domain: Healthcare Analytics

## Tools & Technologies

- Python

- NumPy
- MySQL
- Power BI
- GitHub

## Project Highlights

- Analyzed 110,527 healthcare appointment records.
- Built SQL queries for attendance and no-show analysis.
- Performed feature engineering and EDA using Python.

- Generated actionable insights to improve appointment attendance rates.
